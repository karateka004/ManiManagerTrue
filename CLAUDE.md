# Кошель — контекст проекта для Claude

Telegram Mini App для учёта личных финансов: клиент (данные в браузере + облачная копия за
TG-аккаунтом) и бэкенд на Cloudflare Worker (бот, облако, рейтинг, рефералы, отзывы, админка).

- **Бот:** @TrueManiManager_Bot · **Прод:** https://karateka004.github.io/ManiManagerTrue/
- **Worker:** https://koshel-worker.karateka004.workers.dev · владелец — chat_id `439944083` (Святослав)
- **Язык:** UI, комментарии и ответы пользователю — по-русски. Обращение в интерфейсе — на «ты».
- История релизов подробно — в `src/lib/whatsnew.ts` и `git log`; здесь только то, что нужно для работы.

## Стек и команды
React 18 + TS 5.6 + Vite 5 + Tailwind 3 (`darkMode: 'class'`) + Zustand 5 (persist) + framer-motion 11
(LazyMotion) + dayjs. Бэкенд: Cloudflare Workers + Wrangler 3, KV `REFERRALS`. План Cloudflare — Paid.

Фронт (корень): `npm run dev` (:5173) · `npm run lint` (tsc + `scripts/check-tw-opacity.mjs` + `scripts/test-sync.mjs`) ·
`npm run build` (`dist/`).
Воркер (`worker/`): `npm run lint` (типы + сверки списков с приложением + все тесты: entry 105,
reply, analytics 68, reminders 84, answer 136, csv 12, sync 15, media 32, promo 9, storage 10, channel 26, clarity 62) · `npx wrangler dev --local --port 8787` +
`node scripts/test-webhook.mjs` (сквозной прогон без Telegram) · `npx wrangler tail`.
Сценарии в браузере — `scripts/e2e/` (Playwright; в зависимостях его нет: `npm i --no-save playwright` +
`npx playwright install chromium`): `npm run build` → `npx vite preview --port 4180` → `node scripts/e2e/<имя>`
(`BASE=` — другой адрес): `quickstart` (44 проверки), `quickstart-taps`, `balance` (34), `balance-touch`, `keypad`
(касания CDP), `dark-audit [dark|light]`, `clarity-privacy` (что уходит в Clarity; загрузчик и clarity.js
качает в `.cache/`). После деплоя: `node scripts/e2e/pages-compare.mjs` (dist == Pages побайтно; на Windows с `core.autocrlf=true`
`index.html` и `flags/LICENSE.md` расходятся только концами строк — рабочая копия в CRLF) и
`node --import ./worker/scripts/ts-resolve.mjs scripts/e2e/admin-live.mjs` (живая админка == код).

**Деплой:**
- Фронт — пуш в `main` → Actions «Деплой приложения» (`deploy-app.yml`, gh-pages встроенным токеном).
  Прогон зеленеет, когда Pages отдаёт новый бандл (имя ищется в `dist/index.html`). С веток разработки

  файл**. Через пайп нельзя (PowerShell обрезал токен). Никогда не проси у владельца ключи в чат.
  Локально — `worker/.dev.vars` (не в git; фиктивный после прогонов удалять).

Локально у владельца (Windows): проект `C:\Users\Юля\Desktop\ManiManagerTrue`, конфиг превью — только

## Правила работы
- Коммит и пуш — когда просят (деплой = пуш в `main`). Ветка разработки — из системного промпта.
- В коммитах/PR не упоминать модель. Банковские/личные данные (CSV и т. п.) не коммитить.
- В аналитику и рейтинг — только геймификация, никаких денежных сумм.
- После правок стартового кода сравнивай размер `index-*.js` со сборкой прошлого коммита
  (`git worktree` в scratchpad — см. «Грабли»).
- **При заметном релизе:** `APP_VERSION` (`src/lib/introKeys.ts` — его читает стартовый чанк) + запись в
  начало `RELEASES` (`src/lib/whatsnew.ts`, ru/en).

## Карта кода
**Стор** `src/store/transactions.ts` — persist `finance-mini-app:v1`, **version 18**, миграции
лесенкой `if (version < N)` (новое поле → бамп версии + ветка). `sanitizePersisted` в `merge`:
не теряет данные; незнакомые строки (валюта/язык из будущей версии) НЕ стирает — только значения
не того типа. Селекторы мемоизированы сравнением с прошлым результатом (`memo1`/`memo2`,
`sameResult`); селектор, возвращающий новый объект, без мемо — нельзя. Финансовые селекторы читают
`activeTransactions(s)` (демо или реальные); профиль/задания/подсказки — `s.transactions`.
Запись операции — `commitTransaction` (одно изменение стора; `{ focus:false }` для слива бота),
отмена — `undoCommit`, удаление/возврат — тостом. Экшен без изменений возвращает `s`, а не `{}`
(иначе новое состояние будит всех подписчиков); persist пропускает запись неизменившегося стора. `track(event)` — счётчики заданий в `events`.
Запись persist (`throttledStorage`): JSON полей кэшируется по ссылке (`stringifyPersisted` — байт в байт как
`JSON.stringify`; список операций не пересобирается ради смены периода); смена только полей вида
(`LAZY_KEYS`: период, счёт, `events`, шапка, стиль диаграммы) на диск не пишется — уходит со следующей
правкой данных или при сворачивании (точка сравнения — `seedPersistLast` после гидратации). Читаешь блоб
из localStorage напрямую — сначала `flushPersist()`. Даты операций — `parseDay` (кэш по строке).
Категории — `src/store/categories.ts` (бот сверяет список `check-categories.mjs`).

**Навигация** (`src/App.tsx`): вкладки `home · analytics · rewards · profile` (`TabBar` — плавающая
пилюля + круглая «+»), `settings` открывается из Профиля. Переходы — CSS (`.tab-in-r/-l/-deep/-back`),
прокрутка запоминается по вкладке. **Свайп влево/вправо — карусель:** открытая вкладка в потоке
документа, соседние (`keptFor`, порядок `SWIPE_ORDER`) и уже открытые (`keepWith`, кроме Настроек)
отрисованы и скрыты (`.tab-panel[data-off]`: fixed + `content-visibility: hidden` — браузер не
считает их стили и раскладку и хранит посчитанное, показ ~2 мс; фолбэк `visibility` для iOS < 18).
`inert` на панелях нет: наследуемый флаг стиля, его снятие пересчитывало всю страницу. Новую скрытую
панель `Prewarm` считает в простое, монтаж соседей — `startTransition`. Жест ведёт обе панели 1:1
(соседу ставит inline `contentVisibility`) и переключает без анимации появления (`NavDir 'swipe'`). Хук `src/lib/useSwipeNav.ts` (типы), движок — ленивый
чанк `src/lib/swipeEngine.ts`: touch-события, `touchmove` не пассивный, сдвиг снимается всегда
(touchend/cancel, новое касание, `deactivated`, скрытие, resize). Скрытая вкладка не должна вести
себя как открытая: эффекты «при открытии», «Назад» и прокрутку окна гейтить `useTabActive()`
(`lib/tabActive.ts`, см. Rewards); замеры раскладки внутри скрытой панели форсируют её расчёт —
тоже гейтить (`useSegPill` на скрытой ставит плашку в простое). На Настройках «назад» показывает Профиль под пальцем, на
под-экранах «Прогресса» — тянется с сопротивлением. Вертикальные свайпы Telegram выключены на всё
время (`lockVerticalSwipes` в App). Жест не перехватывается: в шторках (`aria-modal`), в полях ввода,
у края экрана (16 px), на лентах с прокруткой вбок и на `data-swipe-ignore` (карусель целей,
голограмма, меню периода). Новый горизонтальный жест — помечай `data-swipe-ignore`. Проверка —
касаниями через CDP `Input.dispatchTouchEvent` (puppeteer), не мышью.
«Назад» Telegram и Escape — одна стопка `useBackButton`/`pushBackHandler`; свои слушатели Escape
не заводить. Подтверждения — `confirmAction` (не `window.confirm`), копирование — `copyText`.

**Экраны:** `src/pages/` — Home, Analytics (вкладки Расходы/Доходы/Динамика/Календарь), Rewards

## Производительность
Стартовый JS: index (Home) + react + vendor ≈ 131 КБ gzip (2.8.1: index 81 + react 43 + vendor 6; в 2.8.0 было
149 — в vendor лежали все иконки приложения). lucide-react НЕ в `manualChunks`: иконка едет с тем экраном,
где нужна. Шрифт (латиница и кириллица Manrope) — `<link rel=preload>` из index.html (плагин
`preloadFonts` в `vite.config.ts`, `fetchpriority=low`), набор со знаком валюты — `warmFonts` в `main.tsx`:
иначе файл запрашивался на первой раскладке, приходил позже, и страница раскладывалась второй раз (с
перескоком текста). Первый экран — без проявления (`ENTER_CLASS.init = ''`). Прогрев чанков вкладок — по
одному в паузу (`usePrefetchTabs`). Остальные вкладки, шторки, онбординг — `lazyRetry`
(повтор + разовая перезагрузка при устаревших чанках). framer — только `m.*` под
`<LazyMotion strict>` с асинхронным `domMax`; framer НЕ в `manualChunks`. Стартовый чанк не
импортирует `whatsnew.ts` (ключи — в `lib/introKeys.ts`). Persist пишет с троттлингом 400 мс и
сериализует в простое (`flushPersist` при сворачивании и перед чтением блоба). Тема и акцент —
в `main.tsx` до первого кадра и `ready()` (`applyInitialAppearance`). `html.perf-low`/`anim-paused`
гасят бесконечные анимации, `perf-low` — и размытие панели вкладок. Замеры — CPU ×4 на ~2 400
операциях (сценарии вкладок, периода, свайпа, шторки, поиска; трасса Chromium с `elementCount`).

## Грабли
- **Не прятать данные за framer `initial:{opacity:0}`** — при остановленном rAF (свёрнутый webview)
  контент остаётся невидимым. Появление — CSS (`.tab-enter`, `.stagger`, `.grow-*`), данные стоят в
  DOM в конечном виде. framer остался у шторок и онбординга.
- **framer — только `m.*`**, `motion.*` падает в рантайме (`strict`).
- **Нажатия — `.press/.press-soft/.press-icon`**: их `transition` перебивает утилиты того же элемента;
  переход другого свойства — на обёртке.
- **Tailwind молча не генерирует прозрачность вне шкалы** (`/16`, `/12`) — пиши `/[.16]`;
  сторожит `check-tw-opacity.mjs`.
- **`formatMoney` печатает модуль** — для сумм, уходящих в минус, `sign={value < 0}`.
- **Замеры «до/после» — в `git worktree`**, не `git stash` и не `git checkout -- файл` (откатывает
  правки) — сначала коммит. `vite.config.js`/`.d.ts` и `*.tsbuildinfo` — вывод `tsc -b`, не в git;
  `vite.config.js` перекрывает `.ts`, поэтому конфиг правь в `.ts` и пересобирай.
- **Шрифты не встраивать в CSS** (`assetsInlineLimit`): CSP `font-src 'self'` блокирует `data:`.
  После сборки в `dist/assets/index-*.css` не должно быть `url(data:font`.
- **`\b` в JS не видит кириллицу** — граница слова `(?![\p{L}\p{N}-])`.
- **CSS-переменную, которая меняется каждый кадр, не ставить на `<html>`** — её наследует весь
  документ, и стиль пересчитывается у всех страниц (так свайп давал рывки по 70 мс под CPU ×4).
  Ставь на сам элемент (`--tab-swipe` — на капсуле панели).
- **Наследуемое не переключать и не анимировать на больших поддеревьях** (`visibility`, `inert`,
  `pointer-events`, `color` у `body`): каждое изменение — пересчёт стилей всех потомков. Прятать —
  `content-visibility`, двигать — `transform`/`opacity`.
- **Задержки каскада — `animation-delay` на самом элементе, не CSS-переменная** (`--d`): переменную
  наследуют все потомки, и её снятие после показа пересчитывало и раскладывало весь список (~220 мс под
  CPU ×4 через 0,8 с после запуска).
- **`scrollIntoView` двигает страницу** — ленты прокручивать `scrollTo` самого ряда.
- **Эффект шторки зависит только от `open`** (`onClose` у вызывающих — новая функция на каждый рендер).
- **Записи в стор при открытии быстрого старта нельзя** — сохранённый стор = «старый пользователь».
- **Число операций в замерах — из стора**, не из localStorage (persist пишет с задержкой).
- **`wrangler dev` ругается на кириллицу в метаданных KV** — локальный артефакт, на проде нет.
- **График админки:** `viewBox` — по фактической ширине блока; потоки и накопления — на разных осях.
- **Классы в админке — с префиксом блока** (`fn-*`, `src-*`, `ch-*`): общий `.top` у шапки и у строк
  воронки делал строки липкими с фоном страницы — они налезали на вкладки чёрными плашками.
