# Парсер вакансий → Telegram

Cloudflare Worker, который каждые 3 часа собирает свежие вакансии вокруг Роттердама
(3015 BA, радиус 30 км), анализирует их под ваш профиль и присылает подходящие в Telegram.

**Профиль (меняется в `src/config.ts`):** двое, 21 и 19 лет, украинский/русский + английский
(без нидерландского), BSN есть, машина есть, нужен fulltime от €14/час брутто.

## Что умеет

- **Источники:** Adzuna API (агрегатор Indeed/агентств, основной — работает каждый прогон)
  + 4 сайта агентств напрямую: **tempo-team.nl, randstad.nl, uitzendbureau.nl, youngcapital.nl**
  (HTML + микроразметка JobPosting). HTML-источники чередуются группами по 2 за прогон
  (лимит подзапросов воркера). Сбой одного источника не валит прогон.
- **Анализ каждой вакансии:** извлекает ставку (в час/в месяц, NL/EN форматы), график
  (fulltime/parttime), требование языка, минимальный возраст, расстояние от дома.
- **Вердикт:** «подходит обоим» / «только 21+» / отсев (parttime, нидерландский обязателен,
  ставка ниже порога, дальше 30 км). Балл 0–100 + причины по-русски.
- **Telegram:** карточка с кнопкой «Открыть вакансию»; максимум 10 лучших за прогон;
  дедуп — одну и ту же вакансию не пришлёт дважды.
- **Команды бота:** `/start` — подписаться (личка или общая группа), `/now` — проверить
  прямо сейчас, `/stop` — отписаться, `/status` — отчёт о последнем прогоне.
- **Mini App** (кнопка «Меню» в личке с ботом → `GET /app` воркера): лента всех подходящих
  вакансий (KV `feed`, кап 120), фильтры по категориям/поиск/«только обоим», избранное и
  статус «откликнулись» (общие на двоих, KV `favs`), настройки ставки/радиуса/размера
  подборки (KV `cfg`, применяются со следующего прогона), кнопка «Обновить» (= /now,
  кулдаун 10 мин). API `/api/*` защищено подписью Telegram initData (HMAC).

## Установка с телефона (деплой делает Claude)

Если под рукой нет компьютера, всю установку выполняет Claude из сессии Claude Code.
От тебя два действия:

1. **Открыть сеть окружению:** claude.ai → Claude Code → настройки окружения (Environments)
   → Network access → разрешить все домены (или минимум `api.cloudflare.com`,
   `api.telegram.org`, `*.workers.dev` и сайты источников).
2. **Cloudflare API-токен:** в браузере телефона dash.cloudflare.com → My Profile →
   API Tokens → Create Token → шаблон **Edit Cloudflare Workers** → создать → прислать
   токен в чат Claude.

Дальше Claude сам: создаст KV, зальёт секреты (токен бота уже у него), задеплоит воркер,
подключит вебхук и прогонит тест `/run` с отчётом по источникам. Тебе останется написать
боту `/start` с обоих аккаунтов.

> ⚠️ Токен бота, засветившийся в переписке, стоит потом обновить: BotFather → `/revoke`,
> новый токен передать Claude — он заменит секрет `BOT_TOKEN`.

## Установка с компьютера (альтернатива, ~15 минут)

### 1. Создать бота

В Telegram открой **@BotFather** → `/newbot` → имя и username (например, `KoshelJobsBot`).
Сохрани **токен**.

### 2. Ключи Adzuna (бесплатно)

Зарегистрируйся на https://developer.adzuna.com → Dashboard → **Application ID** и
**Application Key**.

### 3. Создать KV и задеплоить

```bash
cd job-parser
npm install
npx wrangler kv namespace create JOBS
# → выведет id — подставь его в wrangler.toml вместо ПОДСТАВЬ_ID_ПОСЛЕ_kv_namespace_create
```

Секреты — через файл (НЕ через пайп в PowerShell, он режет токен!). Создай `_secrets.json`:

```json
{
  "BOT_TOKEN": "токен из BotFather",
  "ADZUNA_APP_ID": "из шага 2",
  "ADZUNA_APP_KEY": "из шага 2",
  "RUN_KEY": "придумай-длинный-случайный-пароль"
}
```

```bash
npx wrangler secret bulk _secrets.json
# сразу удали файл:
del _secrets.json
npx wrangler deploy
```

### 4. Подключить вебхук бота (команды /start, /stop, /status)

Подставь свои значения (`<WORKER_URL>` — адрес из вывода deploy,
вида `https://vacancy-parser.<аккаунт>.workers.dev`):

```bash
curl.exe "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=<WORKER_URL>/webhook&secret_token=<RUN_KEY>"
```

### 5. Подписаться и проверить

1. Напиши боту `/start` — с твоего аккаунта и с аккаунта девушки.
2. Ручной прогон с отчётом по источникам:
   ```bash
   curl.exe "<WORKER_URL>/run?key=<RUN_KEY>"
   ```
   В ответе JSON: `sources` — сколько вакансий нашёл каждый источник (и ошибка, если упал),
   `fresh` — новых, `matched` — прошли фильтры, `sent` — отправлено карточек.

Дальше всё само: cron гоняет парсер каждые 3 часа с 07:00 до 22:00.

## Диагностика

- `npx wrangler tail` — живые логи воркера.
- `/status` боту — отчёт последнего прогона.
- **`sources[].found = 0` с ошибкой у HTML-источников** (tempo-team/randstad/uitzendbureau/
  youngcapital) — сайт сменил разметку или закрылся ботозащитой. Это ожидаемый риск
  HTML-скрапинга: правь `listingUrls`/`linkRe` в `src/sources/*.ts` (источники писались без
  доступа к живым сайтам — сеть среды разработки была закрыта; Adzuna работает по
  документированному API и надёжен). Проверить обе группы сразу:
  `/run?key=…&group=0` и `/run?key=…&group=1`.
- Первый прогон пришлёт много вакансий (всё свежее за 7 дней), дальше — только новое.

## Настройка под себя (`src/config.ts`)

| Параметр | Дефолт | Что значит |
|---|---|---|
| `minHourlyEur` | 14 | ставка ниже — отсев; без ставки — пометка «уточнить» |
| `radiusKm` | 30 | максимум км от дома |
| `minScore` | 60 | порог балла для отправки |
| `maxPerRun` | 10 | карточек за прогон |
| `languages.dutch` | false | появится нидерландский — поставь true, отсев по языку исчезнет |
| `preferredKeywords` | склад/производство/доставка/клининг | за совпадение +10 баллов |

После правки: `npx wrangler deploy`.

## Перенос в отдельный репозиторий (по желанию)

Код самодостаточен — GitHub нужен только как хранилище (cron живёт в Cloudflare).

1. Создай на GitHub пустой репозиторий, например `job-parser`.
2. Из папки `job-parser/` этого репозитория:
   ```bash
   cd job-parser
   git init
   git add .
   git commit -m "Парсер вакансий → Telegram"
   git remote add origin https://github.com/karateka004/job-parser.git
   git push -u origin main
   ```

## Приватность и лимиты

- В Telegram уходят только карточки вакансий; персональные данные никуда не отправляются.
- Бесплатного плана Cloudflare хватает с запасом: ~6 прогонов в день, каждый укладывается
  в лимит 50 подзапросов (источники + KV + отправка двум подписчикам).
- Adzuna free tier: 250 запросов/день — используем ~12.
