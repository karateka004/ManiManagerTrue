# Референсы

Положи сюда скриншоты, на которые ориентируешься.

Claude Code посмотрит на них, когда ты упомянешь файл в промте:

```
Изучи docs/references/screen1.png и обнови стиль шапки под него.
```

Сейчас сюда стоит положить:
- скриншоты Monefy с балансом и категориями
- скриншоты доната с иконками
- скриншоты любых других финтрекеров, которые нравятся
