# Дизайн-система «Кошель»

Эстетика: **soft mint + playful colors**. Вдохновлено Monefy.
Спокойный зелёный как фирменный, тёплые яркие акценты для категорий,
много воздуха, скруглённые формы, мягкие тени.

### Палитра категорий
Каждая категория имеет свой `color` — теплая, насыщенная, но не кислотная.
См. `src/store/categories.ts`. Иконка категории на 22% прозрачности — фон,
сам цвет — акцент в прогресс-баре и точках.

## Типографика

- **Шрифт:** Manrope (400, 500, 600, 700, 800)
- **Числа:** `font-variant-numeric: tabular-nums` через утилиту `.tabular`
- **Иерархия:**
  - Display: 2.75rem / -3% letter spacing / 700 (`text-display-lg`) — баланс
  - Headline: 1.5rem / -1% / 700 — заголовки страниц
  - Body: 1rem / 500 — основной текст
  - Caption: 0.75rem uppercase tracking-widest — оверлайны и метки

Не использовать тонкие веса (≤400) для важной информации — на маленьких
экранах в Telegram они теряются.

## Радиусы

- `rounded-2xl` (16px) — кнопки в numpad, бэйджи, иконки в кружках
- `rounded-3xl` (24px) — карточки
- `rounded-4xl` (32px) — балансовая карточка, главные блоки
- `rounded-5xl` (40px) — BottomSheet
- `rounded-full` — все «пилюли» и FAB

## Тени

- `shadow-soft` — на статичных карточках, едва заметная
- `shadow-raised` — на главных героях (балансовая карточка)
- `shadow-fab` — на FAB-кнопках, заметная, направлена вниз

## Анимации

- Заходы — `framer-motion` с easing `[0.16, 1, 0.3, 1]` (мягкий out)
- Все длительности — 200-400ms, не дольше
- Haptic feedback на ВСЕХ интерактивных элементах:
  - `select` — выбор таба / категории / месяца
  - `light` — открытие/закрытие
  - `medium` — нажатие FAB
  - `success/warning/error` — после действия

## Принципы

1. **Числа крупные и моноширинные.** Финансы должны хорошо читаться.
2. **Цвет несёт смысл.** Зелёный — доход, красный — расход. Не наоборот.
3. **Меньше элементов, больше воздуха.** Категория = иконка + название +
   сумма. Точка.
4. **Контекст в шапке, действие внизу.** Большой палец касается низа экрана.
5. **Анимация подтверждает, не развлекает.** Каждая должна объяснять,
   что произошло.
